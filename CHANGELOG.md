# Changelog

## 1.0.0 — 2026-10-19
First public version.
- Latin text of all nine books (Itinera Electronica digital text), one verse per line, 88 misprints corrected.
- Chinese verse translation of all 6,730 verses directly from the Latin, with 1,204 commentary notes and 177
  textual notes; independent AI review of every book; proper names harmonised (823 entries).
- Scansion of every verse as dactylic hexameter; 515 verses corrected by review agents.
- ElevenLabs recitation script with delivery tags (568 tags); stand-alone voicing script in `tts/`.
- Line-addressed data: JSONL, TSV, TEI P5; parallel Markdown text; typeset PDF (363 pages).
- Tools for validation, regeneration and typesetting; CI checks on every push.
