# 第五卷审校记录

## 译文改动

30：这是此刻；往日它以黄金束起…… → 此刻如此；往日它以黄金束起……（“这是此刻”不成话；Tunc 指此刻披散，与 olim 往日束起相对）
62：那时特洛伊在波涛上， → 那时特洛伊在波涛上、（标点：tremuit 兼管 Troia 与 Roma，改顿号使“战栗”统摄两句）
92：我们也曾有过自己的命运 → 我们也曾有过自己的时运（sua fata 指她也曾有过的好时运、王者尊位，“有过自己的命运”语义空泛；并加注）
186–188：时而想起印在他脚上的吻、/ 轻轻握住的手、泪人儿含泪的胸脯，/ 和她泪光盈盈的眼睛——都燃着甜蜜的火星。 → 时而又为那印在他脚上的吻、/ 那轻轻握住的手、那哭泣者含泪的胸脯 / 和泪光盈盈的双眼，心中燃起甜蜜的火星。（arsisse 与 cernere、fingere 同为历史不定式，主语是马西尼萨；宾格为 ardere“为……燃烧”的对象，如《牧歌》2.1 ardebat Alexin。原译把吻、手等当作燃烧的主语）
219–220：心中燃着爱火，/ 只要被允许；……所以多有畏惧。 → 满怀炽热的渴望，/ 倘若可以的话；……心怀许多畏惧。（ardet, si liceat：“倘若可以，她也渴望”；“只要被允许”生硬）
277–278：因为他们不是在合法的婚火中燃烧，而是在 / 兵戈的喧嚣之中，并且…… → 因为他们燃起的并非合法的婚火，又是在 / 兵戈的喧嚣之中，而……（原译“不是……而是在兵戈之中”造成拉丁文没有的对立；neque legitimis arsissent ignibus 与 inter armorum strepitus 是并列的两条指摘）
376–377：因为，如果说他有理由抱怨，/ 马西尼萨啊，你却没有劫夺的正当 → 因为，即便你有值得抱怨的理由，/ 马西尼萨啊，那也不是劫夺的正当（tibi 在 si 从句内：马西尼萨纵有对西法克斯的旧怨，也不构成夺其妻的正当理由；另一读法写入注）
387–390：除非我久久寄望于你的美德深深欺骗了我，/ 那么，你来看望你的西庇阿，若无重大的缘由，/ 本不会如此；你宁愿把自己的命运托付给 / 我的信义，以至这样弃绝了旧日的朋友。 → 倘若我久久寄望于你的美德没有深深欺骗我，/ 那么，若非出于重大的缘由，你不会来看望你的西庇阿，/ 也不会把自己的命运托付给我的信义，/ 宁愿这样弃绝了旧日的朋友。（“除非……那么”不成句；且 non … causa … nisi magna 同时管 uidendi 与 ut malles 两项，原译把后者改成了独立的陈述）
515：乘一支临时凑成的船队离开赫拉克勒斯之柱， → 乘一支仓促备下的船队，把赫拉克勒斯之柱抛在身后，（linquentem Columnas 指驶出海峡、越过西界去寻福人之地，“离开”易误解为从那里出发）
