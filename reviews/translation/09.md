- 323：虽然直到终篇才呼唤你 → ——虽然唤你时已近终篇——（sub fine“近终”；quoque 表明并非首次呼唤）
- 327：亲自驾驭，为福玻斯的轭马套上缰辔 → 驾驭着福玻斯的轭马，为它们套上缰辔（删去增译的“亲自”）
- 328：而他本人 → 而日神本人（“他”紧接奥罗拉之后，指代不明）
- 393：没有把这里的任何东西带进自己家中 → 不曾把任何财物带进自己的家门（hic 宜作代词“他”，不是“这里”）
- 433：就把许给生前之他的你，交还给入土的他 → 你本是许给在世的他的，就把自己交还给入土的他（“生前之他”半文半白，不通）
- 447：那些更早由更好的时代所生的人 → 那些早先由更美好的时代所生的人（措辞）
- 449：不能倒退回去 → 已不能回到往昔（Non licet ire retro；原译口语化）
- 450：凶残的朱庇特从…… → 冷酷的朱庇特又从……（Et 的“又”，措辞）
- 451：我们必须顺应命运 → 我们必须善用自己的命数（Utendum sorte est）

- 458：终能回到那纯净的古代光辉 → 将能重返那纯净而古老的光辉（poterunt“将能”，purum priscumque 二形容词并列）
- 465：在那样的人们中间 → 在那时的人们中间（illo in populo 指未来的世代）
- 467：但在此期间，我吩咐你，你要这样穿过 → 然而在此期间，我嘱咐你：你要穿过（hec 指诗卷“你”，不是“这样”）
- 468：各族人民怠惰的人群 → 各族怠惰的人群（删去重复）
- 469：只在最外边的门槛被人远远招呼一声，便离去 → 只在门槛的最外边，被人远远地勉强问候一声，便告离去（补出 Vix“勉强”）
- 482–483：那摧毁一切的唯一者——贪婪的时间 → 那践踏万物的唯一者——饕餮的时间（proterit“践踏”；edax 是“吞噬、贪食”，不是“贪婪”）
