## 译文改动
- 4–5：心中把一桩桩事反复思量：那些在幽影中／所见的，都是夜间的安眠带给他的。→ 心中逐一回想那些在幽影里看见、／由夜间的安眠带给他的景象。（que uisa … intulerat 是 Singula 的关系从句，原译拆成独立判断句）
- 12–14：在哪一片土地上有坟墓，／专横的命运女神又会留下怎样的死法，／给我…… → 在哪一片土地上的坟墓、／哪一种死法，专横的命运女神会留给／我，或留给我的兄弟（sepulcrum 与 genus mortis 同为 reseruet 的宾语，原译“有坟墓”脱离了谓语）
- 124：扫视屋顶 → 扫过屋顶（cauda perlustrat，用尾巴扫过，非“扫视”）
- 149–151：把双角向巨大的圆周／舒展开去，手中握着……清晰可见 → 双角张开，弯成巨大的弧圈，／可以看见他手执灵巧的三叉戟，用来约束／海水（措辞生硬；cernebatur 管 ferre，挪到所支配的分句）
- 157：此处是孩童，此处是少年，不过多久 → 时而是孩童，时而是少年，不消多久（与注所述太阳随季节变换年龄相合）
- 184：那大理石般的老人 → 化作大理石的老人（marmoreus 指已成石，不是“像大理石”）；注 181–185 同步改
- 261：捻着弯曲丝线的 → 捻着丝线的（torto stamine 是捻成的线，“弯曲”误）
- 265–266：认定没有什么比纯金更卑贱，／把人们视为珍奇之物都踩在脚下 → 发觉这里最不值钱的也是纯金，／脚下踩的尽是世人视为珍奇的东西（agnoscit 写所见：宫中最贱的材料也是纯金，地面铺满珍宝；参卢坎第十卷克娄巴特拉宫“缟玛瑙任人踩踏”。原译与原注作斯多葛式鄙视黄金解，依据不足）
- 267：穿过宏大殿堂那遥远的重重边界 → 穿过宏大殿堂的重重区域，走了很远（procul 修饰行程，不修饰 finibus）
- 335：我也不敢轻视 → 我也决不轻视（despicio 无“不敢”之意）
- 415–416：那血以滴淌的／腐液中可憎的脓汁 → 那血带着滴淌的／腐败与可憎的脓液（不通顺）
- 435：倘若这两位热爱祖国的人当初不肯献出生命 → 倘若他们当初贪生，不肯把性命献给祖国（patrie 是 negassent 的与格，cupidi 指贪生；“热爱祖国”432 行已说过）
- 459：最好的国王啊 → 最贤明的国王啊（两部分统一 Optime rex 的译法，同 271 行）
- 537：哺育人的科尔涅利乌斯家门 → 慈惠的科尔涅利乌斯家门（alma，与 185 行“慈惠缪斯”一致；原译不通）
- 587：那逃遁的长矛，最末一截颤动着，堪堪越过。→ 那逃遁的长矛颤动着，最末一截堪堪没入其中；（“越过”不明所指，改得与注 586–591 的解释一致）
- 598：便停住脚步，凶猛地叹息 → 便停下来，激愤地长叹（ferox 在此是激昂，“凶猛地叹息”不通）
- 777–778：你会看到，成双的／新标志骤然承载起节制有度的官职 → 你会看到节制有度的／官员骤然执掌起成双的新标志（modestos magistratus 是不定式 ferre 的主语宾格，signa 是宾语；原译主宾颠倒）
- 800：这位贞洁的复仇者 → 这位为贞洁复仇的人（ultor pudicitie 是贞洁的复仇者，原译有“贞洁的人”的歧义）
