# 第一卷审校记录

## 译文改动

- 10：把心气还给他。还有你，啊，世界最确实的 → 把心志还给他。还有你，啊，世界最笃定的（“心气”偏口语；“确实的希望”不成词，certissima spes 译“最笃定的希望”）
- 17–18：或许还有眼泪——（我的心就这样自欺）／我这愚人久久留存，为的是有朝一日向你倾洒。 → 或许还有眼泪——我的心就这样欺骗自己——／我这愚人久久留存着它们，要在将来向你倾洒。（破折号加括号重叠；补出 quas 的指代）
- 19：你也是——特里纳克里亚王国至伟的统治者， → 还有你，特里纳克里亚王国至伟的统治者，（“你也是——”起句不通，Te quoque 是呼告）
- 23–24：我也祈求你：以宁静的胸怀，将这献上的礼物／纳入你的款待吧 → 我也向你祈求：请以宁静的胸怀，把这献上的礼物／迎作你的宾客吧（“纳入你的款待”不通；Hospitio dignare tuo）
- 31：便能使原本不配的他变得配得上。 → 便使本来不配的他成了配得上的人。（Effecisse potes 指已成之事：国王已使诗人得冠）
- 34：能为我赢得多大的恩宠！ → 能为我赢得多少青睐！（fauori meo 指世人对诗人的好感，不是君王的“恩宠”）
- 38：……诸王中的名君，收下它吧， → ……诸王中的名君，就收下它吧，（补出 tandem 的催促语气）
- 69：于是应得的荣耀将归于爱戴你的人： → 那应得的荣耀将归于这心怀爱慕的人：（amanti 未说爱慕对象，可指国王，也可指桂冠／劳拉，译文保留歧义，并在注中说明）
- 115：被风暴折腾得精疲力竭 → 已被风暴摧折得精疲力竭（“折腾”口语）
- 119–120：他们畏惧这位统帅的胆魄、他那如雷霆般／闪电似的右手 → 他们畏惧这位雷霆般的统帅的胆魄，畏惧他／闪电般的右手（原译叠床架屋；tonantis 指统帅，fulmineam 修饰右手）
- 191：它们因我应得而神圣 → 它们于我理当神圣：（sacra mihi merito，“理当”是 merito 的副词义）
- 213–217：……它的惊愕／也不过如那神圣的合唱队。因为愤怒只到下界为止，／还有痛苦……／最可悲的忧虑——我们用它们消磨了 → ……它的惊愕，／正如那神圣的合唱队那时的惊愕。因为愤怒仅存于此间，／痛苦……／最可悲的忧虑，也都如此——我们在忧虑中消磨了（non aliter … quam 是“正如”，“不过如”有贬抑意；原句“只到下界为止，还有痛苦……”不通）
- 249：他向他们提起神明、法理、天道——都是空话！ → 我兄弟向他们搬出神明、法理、天道——全是空话！（ille 指格奈乌斯，原译“他”所指不明；obicit 是“拿来责问”）
- 271–272：扑向那个讨厌的脑袋……／坚持他的勾当 → 扑向那侵扰者的头颅……／执意不舍（语体过俗；Inceptique tenax）
- 285：士兵们，从这条路上，崇高的光荣之死已经敞开。 → 士兵们，这里敞开着一条通往光荣之死的险路。（hac 为副词，uia 是主语，ardua 修饰 uia“陡峭的路”，不是“崇高的死”）
- 289–290：马尔斯以少许的鲜血／换来巨大的荣耀 → 马尔斯只索取少许的鲜血，／便献上巨大的荣耀（obicit 是马尔斯“献上”荣耀，不是“换来”）
- 316：我们杀敌，也纷纷战死 → 我们杀敌，青年们也纷纷战死（moritur 主语是 315 行的 pubes，并非讹误）
- 331：你的、你的孝爱，亲爱的父亲 → 你的、你的慈爱，亲爱的父亲（pietas 属父亲，“孝”只能用于子女）
- 357：认得他们的风度、衣着和步态； → 认得他们的风度、衣着和步态……（残行，按译者须知以省略号示缺）
- 360：你记得不错。 → 你说得不错。（memoras 是“你说”）
- 361：夺走了这个人。他在不利的境地…… → 夺走了这个人。……他在不利的境地……（残行，Punica 之后缺约一个半音步，以省略号示缺）
- 383：他认为罗马的命运已在坎尼之日被哭到了尽头， → 他以为坎尼之日已是为罗马命运举哀的末日，（原译不通；defleta supremum 是“最后一次被哀悼”，即以为罗马已亡）
- 394–395：可是命运和凶猛的／我那同僚 → 可是命运与我那凶猛的／同僚（语序不通）
- 416–418：显然，凶猛的汉尼拔一心加害，热忱无比，／使罗马城失去了勇敢的公民，变得贫乏，／他却也用你们的亡魂充满了天空。 → 原来，当凶猛的汉尼拔不遗余力地设法加害，／当他夺走罗马城勇敢的公民、使它变得贫乏，／他却用你们的亡魂充满了天空。（两个 dum 从句译成时间从句，显出“本想加害、反充满天国”的反讽；“热忱”褒义不当）
- 507：”他说， → ”伯父说，（ait 承 499 行，点明说话人，与注一致）
- 508：那著名之名的创立者 → 那显赫之名的创立者（“著名之名”重复）
- 540：最亲爱的儿子 → 我最亲爱的孩子（说话人是伯父；fili 为亲昵称呼，加注说明）
- 574：也同样高兴，因为他们死得有仇得报，才升到天上。 → 也同样欢喜：他们升入天界，死得并非无人复仇。（原译“才”误成条件关系；nec inulto funere missi）
- 段落标题 @419-459：伯父格奈乌斯开口 → 西庇阿与伯父格奈乌斯交谈（419–436 行说话的是西庇阿与父亲，伯父 437 行才开口）

## 注释改动

- 注 4-5：改写。surgere 若保留并非不可解（“祈求圣泉重新涌出”），作为异文处理；从 Festa 读 sugere。
- 注 10-14：“传说”改为“信条”（下降阴间是信经条文）；补 summe parens 称基督的说明。
- 注 16-18：新增，说明“眼泪”指忏悔之泪及括号里的自责。
- 注 62-64：原说“像 1341 年那样带回罗马的桂冠”，与史实不合（1341 年受冠后并未回那不勒斯）；改为设想再受一次桂冠并带回那不勒斯。
- 注 70 → 69-70：补 amanti 的两解（国王／桂冠—劳拉谐音）。
- 注 88-90：删去与本行无关的“仇恨甚于实力”，移入注 109-114（对应 109 行 grauibus certatum odiis）。
- 注 214-221：补一句对应新译文。
- 注 230-236：补“此处赫斯珀里亚指西班牙”。
- 注 234：新增，infelix 的两种读法（译者所疑）。
- 注 256-258：“小西庇阿”通常指西庇阿·埃米利亚努斯，易混，改为“本诗主人公西庇阿”。
- 注 266-276：删去“维吉尔称蜜蜂为虔敬的一族”（无法确认），改为说明 273 行的称呼。
- 注 309-311：新增，recolenda 可承 cohors 或 Mors（译者所疑），说明今译依据。
- 注 316：改写，moritur 的主语是 pubes，不是讹误。
- 注 353-355：引语与译文对齐（“倘若这里还挂念他们”）。
- 注 357：改正残缺程度（末尾约缺一个半音步，不是两个音步），说明省略号。
- 注 360-363：说明 361 行的缺口位置与省略号。
- 注 371-377：补出时代错置：梦境在约前 206 年，法比乌斯前 203 年才去世。
- 注 501-511：说话人的证据写全（506 ait 承 499；540 fili；584 nepos；589 pater）。
- 注 540：新增，伯父称侄儿为 fili 的缘由。
- 注 589-590 → 584-590：补 nepos 的中世纪词义；“第二卷开篇即接写父亲继续说话”改为“由父亲接过话头”（第一卷末说话的是伯父）。
- 另调整两条注释的排列顺序（按起始行号）。

## 仍有疑问之处

- 66 primos：无名词可依，“最初的尝试”是推测。
- 185 uacuisque … bustis：“为空坟集结军队”与“坟冢空空之时”两解并存。
- 241 imparibus … fatis：理解为布匿人害怕在形势不利时正面交锋，仍嫌含糊。
- 309–311 recolenda 的归属（cohors 或 Mors）。
- 361 iniquo 无所修饰；“在不利的境地”是按文意补足。
- 364 Nobiscumue。
- 578 Publicolam ante alios：译作“走在众人之前”，也可理解为“尤其是普布利科拉”。
