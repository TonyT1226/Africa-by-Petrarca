# 第二卷审校记录

总体：译文质量较高，句读、说话人、引号起止基本无误。以下为实质性改动。

## 译文
- 19–20：你们二位，如此伟大的 / 帝国的两盏明灯 → 你们二位——如此强大的 / 帝国那两盏如此辉煌的明灯——（原译漏掉 tam magna“如此辉煌的”，只译了 tanti imperii）
- 110：他在临死之前几番沉重地辗转 → 他在垂死时几番沉重地翻腾挣扎（graues … reflexus 接上第 82–89 行垂死之蛇的比喻，见注）
- 115：要忍受他这样久 → 已经忍受他这么久（sustinet 为现在时：汉尼拔此时仍在意大利，不是将来的事）
- 148：他在此事上更为严酷，那是对方罪有应得，他燃着正当的仇恨 → 他在此事上更为严酷，因对方罪有应得，燃着正当的仇恨（meritis 表原因；原句结构松散）
- 154–155：罗马城从来不曾 / 拥有比那时更多的…… → 罗马城永远不会 / 比那时拥有更多……（non ditior unquam erit 为将来时）
- 168–169：“伟大者”“伟大” → ‘伟大者’‘伟大’（处在父亲的话里，按体例用单引号）
- 303：从来没有一个时代，没有一个 → 永远不会有一个时代——没有一个——（nulla uacabit 为将来时，原译误作过去）
- 353：却把你们卷向深渊 → 却使你们一头栽落（praecipitat 本义为“使倒栽而下”；“深渊”是添出来的）
- 474：不论那是谁，都要蔑视他 → 无论那是怎样的议论，都蔑视它吧（quisquis is est 的 is 为阳性，指上句的 sermo“议论”，不指人；vulgus 是中性）
- 524：“莱利乌斯与西庇阿” → ‘莱利乌斯与西庇阿’（话中引语用单引号）

## 注释
- 注 63：补充 Cultus（复数）的另一解“朴素的衣着与生活方式”，说明今译所取之义。
- 注 89–93：删去“李维本人对此有所保留”（35.14 只是转引，并无明言保留），改为“李维只是转述此说”；删去 festiua 带“反讽意味”的说法（上下文看不出反讽）。
- 注 110–111：补充 dare reflexus 与 dare saltus、dare gyros 同类的句法依据，并把呼应对象由第 89 行改为蛇的比喻。
- 注 117–120：补充 portum tenere“入港”的成语，支持原译“迦太基所泊的港湾”一解；补充迦太基按和约纳贡。
- 注 134：补充西塞罗《论义务》第二卷所记穆米乌斯不取科林斯战利品之事，以说明 spectata modestia。
- 注 139–141：“皆共和晚期的显赫家族”不确（梅陶罗河的克劳狄乌斯·尼禄与西庇阿同时），改为“共和时期”，并作说明。
- 注 141–142：“经收养承袭了家名”只说对一半，补充尼禄的母系血统出自提比略·克劳狄乌斯·尼禄，并指出也可能兼指提比略。
- 注 156–159：补充中世纪 Campania 的范围较广，彼特拉克未必有误。
- 注 196–199：补充“红海之滨”（Rubrum litus）的说明。
- 注 214–215：重写：最可能是同位属格，指西西里本身（这份名单有撒丁岛、科西嘉，不应缺西西里）；另一解为附属西西里的小岛。
- 注 238–239：Ephyrea arma 由“所指不能确定”改为当指狄拉基乌姆（卢坎《内战记》第六卷开头称其城墙为 Ephyraea moenia）；Tharson = 塔普苏斯，排除塔尔索斯；改正“击败……小加图”（小加图未参战，战后在乌提卡自尽）。
- 注 244–245：说明“终日”是最自然的理解，“日光所照之处”一解较勉强。
- 注 261–265：补充格律依据：quid mŏrĕ 须构成长短短格，e 为短音，只能来自 morior（moror 的虚拟式 morēris 不合格律），因此译“死去”无误；并点明受呼告的是刚去世的奥古斯都。
- 注 361–367：《西庇阿之梦》6.20 并未提到沼泽、森林，改为如实说明这是彼特拉克的发挥。
- 注 397–400：补充把 Hibernum 解作爱尔兰的理由（中世纪地图上爱尔兰在最西端；本卷伊比利亚都写作 Hiberus），保留另一解。
- 注 449–454：原注只是复述原文，改为补充恩尼乌斯与西庇阿的关系（西塞罗《为阿尔基亚斯辩护》：西庇阿家族墓中有他的像），并点明彼特拉克借此申明自己的写作动机。

## 译者所提疑点的复核结论
- 110–111 graues … reflexus：同意译者的读法（名词复数宾格，作 dederit 的宾语），并补充了句法依据。
- 117–120 apprendere portum：同意，portum tenere 的成语支持这一解；第 120 行的 illa 指迦太基或指胜利，两解都通。
- 134 Memmi：同意当指 L. 穆米乌斯；译名保留梅米乌斯，加注说明。
- 214–215 clipeus Trinacriae：仍有疑问，倾向于指西西里本身。
- 238 Ephyrea arma：同意指狄拉基乌姆，有卢坎 6.17 的 Ephyraea moenia 为证。
- 239 Tharson：同意即塔普苏斯，拼法可疑，只在 TEXTNOTES 登记，不列入 CORRECTIONS。
- 244–245 per omnem diem：取“终日”。
- 261–265 quid moreris：格律证明来自 morior“死”；呼告对象为奥古斯都，“残存的人群”指其后的朱里亚—克劳狄王朝诸帝。
- 400 Hibernum：倾向于爱尔兰，未能完全排除伊比利亚。
