## 二、译文改动
- 97：营寨坐落在怎样的地势 → 营寨依托怎样的地势（fulsa 当作 fulta“依托、支撑”；文本注同步）
- 109–110：一道道密布的伤疤，／又大又深 → 密密麻麻的伤疤，／道道巨大（ingentes 只是“巨大”，“深”为增译）
- 124：恰好就在 → 或许就在（forsitan）
- 311：盛名流传万世 → 盛名广播万世（补 abunde）
- 315：这位男人战胜不了的人、妇人的荣耀 → 他从未败于男子，却成了妇人的荣耀（原句不通顺；注 312–316 中引文同步）
- 379：神不过是一个空洞的传说 → 说有神不过是空洞的传说（fabula uana est … esse Deum：空洞的是“神存在”之说）
- 393–394：罗马的援军来得太迟，没能救助那些／不幸的人 → 对那场苦难而言，罗马的援军／来得太迟（miserie = miseriae，与格“对苦难”，非 miseris）
- 404：为什么？ → 试想：（Quid enim? 不是问原因）
- 422–423：那些投身于虔敬战争的人，／他惯于用自己的援助来扶持 → 他惯于用自己的援助／扶持投身于虔敬战争的人（去掉生硬的回指，行对应更贴近）
- 544：一位统帅的 → 那位统帅的（与下文 illum、hunc 呼应）
- 726–727：全体都鼓动欢欣的翅膀，／天界众灵和传报和平的天使行列都为他遮荫 → 所有天上的居民都以欢欣的翅膀／为他遮荫，还有那些传报和平的天使行列（接缝处“全体……天界众灵”重复且两段各说一半；改为跨行连贯的一句，Celicole 译名与名表统一为“天上的居民”）
- 872：就连他们的统帅——他比他的年纪更凶悍—— → 就连他们那位凶悍得超出年纪的统帅（ferocior annis；原译欠通）
- 891：我向众神起誓 → 我凭众神恳求你们（per numina testor uos 是“凭众神恳请你们”，宾语是下行的毛里人、努米底亚人，不是发誓）
- 1093–1094：中文把 Vix tandem fessa parumper 整体移到 1094 行；两行现在同段，改回逐行对应：……仇恨。终于，疲惫的／布匿军阵勉强退却了少许。
- 1117：向那些疲惫的…… → 对那些疲惫的敌人……（fessos 作名词，句法完整，只是诗行未写满；省略号保留以示半行）

- 115 Iuistis（见文本注）。
