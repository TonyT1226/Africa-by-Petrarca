# Roadmap · 路线图

Layers that would make the edition more useful for research and for new creative work. Contributions welcome;
open an issue before starting a large piece so the format can be agreed.

## Foundations
- [ ] **Human review** by Latinists, book by book, with a review-status field per section.
- [ ] Confirm the terms of use of the *Itinera Electronica* digital Latin text.
- [ ] Collate the Latin against Festa's 1926 edition and record variant readings.

## Data layers for creators
- [ ] **Speaker attribution** for every verse: narrator or which character speaks (the poem is full of speeches).
  This would enable multi-voice audio, scripts and stage adaptations.
- [ ] **Entity linking**: people → Wikidata, places → Pleiades (ancient places) with coordinates, plus occurrences
  by verse. This would enable maps, timelines and character networks.
- [ ] **Sources and allusions** as data: verse → Livy book.chapter, Vergil/Lucan/Ovid parallels (now only in prose
  notes).
- [ ] **Summaries at several lengths** (one line, one paragraph per section), plus a "story bible" with characters,
  timeline and settings.
- [ ] **Lemmatisation and morphology** of the Latin (e.g. LatinCy), and word-level Latin–Chinese alignment for
  learners.

## Reading and listening
- [ ] Web reader on GitHub Pages: parallel text, notes toggle, scansion view, audio per verse.
- [ ] Recorded audio (e.g. Book IX via `tts/`), with per-verse timestamps from forced alignment.
- [ ] EPUB edition.

## More languages
- [ ] Translations into other languages from the Latin, reusing `methodology/` (briefs, glossary method, review
  loop) and the same line-addressed format.
