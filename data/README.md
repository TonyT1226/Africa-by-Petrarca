# data/ — line-addressed data

Generated by `python3 tools/regenerate.py` from `source/`. Do not edit by hand.
All text is UTF-8. Verse IDs `africa.B.N` are permanent (book 1–9, line N as printed).

| File | One record per | Contents |
|---|---|---|
| `lines.jsonl` | verse (6,730) | Latin, Chinese, scansion, recitation text, delivery tag, note IDs |
| `sections.jsonl` | section (272) | verse range, Chinese title, delivery tag |
| `notes.jsonl` | note (1,381) | commentary and textual notes (Chinese), the verses they cover |
| `books.json` | book (9) | Latin and Chinese titles, counts, Chinese summary |
| `names.tsv` | proper name (823) | Latin forms → Chinese rendering, books where used |
| `corrections.tsv` | correction (88) | misprints of the digital Latin text corrected in this edition |
| `scansion/NN.tsv` | verse | full scansion table per book (see below) |
| `recitation/*.txt` | section | ElevenLabs-ready text, one block per section |
| `tei/africa_NN.xml` | book | TEI P5: Latin edition, Chinese translation, notes |

## lines.jsonl

```json
{"id": "africa.1.1", "book": 1, "line": 1, "section": "africa.1.s01",
 "latin": "Et mihi conspicuum meritis belloque tremendum,",
 "latin_digital": null,
 "zh": "缪斯啊，也请你为我讲述那位以功勋显赫、",
 "scansion": {"pattern": "DDDSDX", "feet": "Ét mihi |cónspicu|úm — meri|tís bel|lóque tre|méndum,", "status": "ok"},
 "recitation": "Ét mihi cónspicuúm — meritís bellóque treméndum,",
 "delivery": "solemn, stately",
 "notes": ["africa.1.n001"]}
```

- `latin`: the verse as printed in this edition (digital text with misprints corrected).
- `latin_digital`: the uncorrected digital text when it differs, else `null`.
- `zh`: the Chinese line. Chinese word order sometimes shifts sense between neighbouring lines of one sentence.
- `scansion.pattern`: six letters, D = dactyl, S = spondee, X = final foot; `null` for half-lines, unscannable
  verses and a few reviewed verses whose pattern cannot be derived mechanically (their `feet` is still given).
- `scansion.feet`: recitation text with `|` between feet; accents mark the ictus (first syllable of each foot).
- `scansion.status`: `ok`, `amb`, `var`, `man` (reviewed), `frag`, `irr` — see `AGENTS.md`.
- `recitation`: text for an Italian TTS voice (ictus accents, elisions with apostrophes, ` — ` at the caesura,
  consonantal u as v, ae/oe as e).
- `delivery`: English delivery tag placed before this verse in the recitation script, or `null`.
- `notes`: IDs of notes whose range covers this verse.

## notes.jsonl

`{"id", "book", "type": "commentary"|"textual", "section", "start", "end", "lemma", "text_zh"}` —
`lemma` is the Latin (occasionally Chinese) words annotated; `section` is `null` for textual notes.

## Quick use

```bash
# one verse
grep '"africa.9.123"' data/lines.jsonl
# all lines of book 4 with jq
jq -r 'select(.book==4) | "\(.id)\t\(.latin)\t\(.zh)"' data/lines.jsonl
```

```python
import json
lines = [json.loads(l) for l in open("data/lines.jsonl", encoding="utf-8")]
spondaic = [l["id"] for l in lines if (l["scansion"]["pattern"] or "").startswith("SSSS")]
```
